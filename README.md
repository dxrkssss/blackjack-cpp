# Blackjack Console Game

A simple console-based Blackjack game written in C++.

## About the Project

This project is a command-line implementation of the classic Blackjack (21) card game. The player competes against the dealer by drawing cards and trying to get as close to 21 points as possible without exceeding it.

## Features

- Standard 52-card deck with four suits.
- Random card shuffling.
- Interactive gameplay.
- Hit and Stand actions.
- Automatic score calculation.
- Winner determination.

## Technologies Used

- C++
- Standard Template Library (STL)
- Object-Oriented Programming (OOP)

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/dxrkssss/blackjack-cpp.git
   ```

2. Navigate to the project directory:

   ```bash
   cd blackjack-cpp
   ```

4. Compile the source code:

   ```bash
   g++ main.cpp -o blackjack
   ```

5. Run the game:

   ```bash
   ./blackjack
   ```

## How to Play

- Press `h` to draw another card (Hit).
- Press `s` to keep your current score (Stand).
- Try to get as close to 21 as possible without going over.
- The dealer draws cards until reaching at least 17 points.
